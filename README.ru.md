## ✨ О проекте

**Seedance Studio Pro** — современная веб-студия для кинорежиссеров, сценаристов и AI-криэйторов. Она предоставляет полноценную рабочую среду для создания многосерийных роликов и каскадных шотов на базе диффузионных видео-трансформеров **ByteDance Seedance** (`Seedance 2.5`, `Seedance 2.0`, `Seedance 2.0 Fast`, `Seedance 2.0 Mini`, `Seedance 1.5 Pro`) через официальный **OpenRouter Video API**.

## 🚀 Ключевые возможности

### 1. 🔗 Каскадная сшивка шотов (Multi-Shot Keyframe Chaining)
* **Бесшовный переход:** Автоматический захват финального кадра Сцены #$N$ и передача его в качестве начального кадра (`first_frame`) для Сцены #$N+1$.
* **Полный контроль режиссера:** Выбор автоматического наследования, выбор ключевого кадра из любой предшествующей сцены или загрузка собственного файла.

### 2. 🛡️ Живой анти-детект фильтр шума (Обход цензора ByteDance Real Person)
* **Обход ошибок приватности:** Встроенный клиентский движок наложения пленочного зерна (~50%), который разбивает биометрические опорные точки лиц для цензора ByteDance (устраняет ошибку `InputImageSensitiveContentDetected.PrivacyInformation`), сохраняя при этом позу, черты лица, одежду и композицию для DiT-диффузии.
* **Предпросмотр в реальном времени:** Интерактивное отображение зашумленного кадра прямо в миниатюрах и в полноэкранном окне (Lightbox).

### 3. 🎭 Мультимодальные референсы и консистентность персонажей
* **Визуальные ориентиры:** Добавление фото персонажей, локаций, стилистики (`[Image 1]`, `[Image 2]`).
* **Копирование тегов в 1 клик:** Быстрая вставка нужного тега в текстовый промпт.
* **Поддержка видео и аудио:** Входные образцы движений камеры/тела (`input_videos`) и синхронные звуковые дорожки (`input_audios`).

### 4. 🤖 Встроенный AI-Режиссер
* **Интеллектуальный промптинг:** Автоматическое обогащение описаний динамикой, соматическими микродвижениями (саккады глаз, дыхание, моргание), векторами камеры и кинематографическим стандартом 24fps Anti-Slowmo.

### 5. 💾 Полное автосохранение проекта (Zero-Loss Persistence)
* **Сохранение на лету:** Все сцены, тексты промптов, углы обзора, загруженные медиафайлы и настройки непрерывно сохраняются в `localStorage` браузера. Проект сохраняется даже при обновлении страницы (`F5`).

### 6. 📥 Автоматическое сохранение MP4 на диск и встроенный плеер
* **Архивация видео:** Готовые ролики автоматически загружаются через авторизованный серверный поток и сохраняются в папку `video/ГГГГ-ММ-ДД/scene_#_время.mp4`.
* **Локальный просмотр:** Встроенный видеоплеер, кнопка прямого скачивания MP4 и модальное окно полноэкранного анализа кадров.

### 7. 📟 Живая консоль логов и телеметрии
* Модальное окно для отслеживания отправляемых JSON-пейлоадов, процесса поллинга, расхода токенов и ошибок API в реальном времени.

## 📦 Быстрый старт

### Требования
* [Node.js](https://nodejs.org/) v18+ (рекомендуется v20+)
* Ключ [OpenRouter API](https://openrouter.ai/keys) с балансом для видеомоделей.

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Siruz645/Seedance.git
   cd Seedance
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Настройте переменные окружения (или введите ключ в интерфейсе студии):
   ```bash
   # .env.local
   OPENROUTER_API_KEY=ваш_openrouter_api_ключ
   ```

4. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

5. Откройте в браузере: [http://localhost:3000](http://localhost:3000).

## 🔒 Безопасность и конфиденциальность

* **Локальное хранение:** API-ключ OpenRouter сохраняется только в вашем личном браузере (`localStorage`) и не отправляется на сторонние аналитические сервера.
* **Исключение медиафайлов:** Все сгенерированные тяжелые MP4-файлы и временные скрипты заблокированы в `.gitignore`, чтобы не перегружать репозиторий.
